# SQL e PostgreSQL — Estudos e Exercícios

Este repositório reúne meus estudos práticos de **SQL com PostgreSQL** com foco na construção de uma base sólida para o desenvolvimento Backend com Java.

Os exercícios estão organizados de forma progressiva, abrangendo desde os fundamentos de SQL até consultas envolvendo múltiplas tabelas e subqueries.

## Conteúdos estudados

### Fundamentos de SQL
- Criação e manipulação de tabelas e registros
- Comandos `SELECT`, `INSERT`, `UPDATE` e `DELETE`
- Filtros e operadores: `WHERE`, `AND`, `OR`, `LIKE`, `IN`, `BETWEEN` e `IS NULL`
- Ordenação e remoção de duplicidades: `ORDER BY` e `DISTINCT`

### Agregações e agrupamentos
- Funções `COUNT`, `MIN`, `MAX`, `SUM` e `AVG`
- Agrupamentos com `GROUP BY`
- Filtragem de grupos com `HAVING`

### Estrutura e relacionamentos
- Constraints: `NOT NULL`, `UNIQUE`, `DEFAULT` e `CHECK`
- Chaves primárias e estrangeiras (`PK` e `FK`)
- Alteração de tabelas com `ALTER TABLE`
- Relacionamentos e consultas com `INNER JOIN`, `LEFT JOIN` e múltiplos JOINs

### Subqueries
- Consultas aninhadas
- Subqueries com `IN` e `NOT IN`
- Filtragem de registros com base em resultados de outras consultas

## Organização do repositório

Os arquivos `.sql` estão numerados sequencialmente, permitindo acompanhar a evolução dos conteúdos e a complexidade dos exercícios.

## Objetivo

Consolidar meus conhecimentos em bancos de dados relacionais por meio da prática, preparando-me para integrar aplicações Java com PostgreSQL no desenvolvimento Backend.
